# 儿童性早熟怎么办？

> 更新时间：2026-09-16 (UTC+8)

性早熟是一种青春期发育的异常，表现为青春期的特征**如生长突增、生殖器官及性征的发育成熟等**均比同年龄儿童明显提前。按性早熟的发病机制，可将其分为真性、假性及部分性早熟3类。性早熟发病率近年有逐渐上升的趋势，女孩发病率为男孩发病率的4~5倍。

PART.01

**如何判断性早熟**

**1**

女孩在8岁以前出现乳房发育、并且伴随小阴唇变大着色、阴毛出现，10岁以前月经初潮。

**2**

男孩在9岁以前出现睾丸增大、逐渐出现阴茎增大、阴毛出现，声音变粗，并出现喉结胡须等。

**3**

男女孩均有生长加速，骨成熟加速。

PART.02

**性早熟的危害**

1.影响成年身高 

2.性行为提前

3.造成自卑心理

4.肿瘤征兆 

PART.03

**促发性早熟的因素**

**1.饮食因素**

过食肥甘厚味或者滋补品如蜂王浆、牛初乳、花粉、鸡胚、蚕蛹等；过量食用高热量、高脂肪、高蛋白、高糖的零食，如薯条、炸鸡、汉堡、可乐、奶茶等；长期食用含有添加剂、性激素的食物都可以引起性发育及性成熟提前。

**2.环境因素**

由洗涤剂、农药及塑料工业向环境排放的物质及其分解产物，可在自然界产生一系列的环境类激素污染物。如洗涤剂中的烷基化苯酚类、制造塑料制品过程中使用的添加剂邻苯二甲酸酯类等（劣质儿童用品如玩具、文具等可能含有），如果经过某些途径如污染水源、食物或经皮肤吸收、被儿童摄入即可与靶器官上的雌激素受体结合，引起生殖器官及骨骼的发育异常。此外误食有性激素的药品（如避孕药）、接触了含有会引起性早熟激素的化妆、护肤品，也可能会导致孩子性早熟。

**3.社会心理因素**

目前在社会的各种传播媒体，如电视、电影、报刊、杂志等内容中,与性有关的内容比以前显著增多，儿童不自主地耳濡目染受到潜移默化的影响，可能会造成下丘脑-垂体-性腺轴的启动相应提前。

PART.04

**预防性早熟的方法**

**01**

**合理膳食，远离肥胖。**饮食中肉、蛋、奶、菜、水果、粗粮多元化搭配，适当补充钙以及维生素D，要少吃热量高的油炸食品，如炸鸡、炸薯条等零食。

**02**

**避免含激素物质。**禁止服用含有性激素类的滋补品、不食用含生长激素合成饲料喂养的禽畜类食物、不使用含激素的护肤品以及儿童用品、不让孩子接触含有性激素药品。

**03**

**培养良好的睡眠习惯。**孩子熬夜玩电脑、开灯睡觉，暴露在人造光源下，导致体内的褪黑素分泌量减少，可能会诱导性早熟。家长要帮助孩子养成早睡的好习惯，待孩子熟睡后，一定要关灯睡觉。

**04**

**增加体育活动。**适当的运动有益于孩子的身心健康，家长要给孩子安排每日运动如慢跑、跳绳、打篮球、跳操等。

**05**

**营造良好的信息环境。**避免孩子接触不良信息，不要让孩子过多接触言情类电视剧、电影、小说等。

**06**

**早发现、早预防、早诊断、早治疗**。儿童成长过程中，养成定期体检和健康评估的习惯。  

PART.05

**中医如何认识性早熟**

中医认为性早熟的内因主要是体质的异常，此类患儿大多属阴虚内热型的偏颇体质，本身潜在着容易出现阴虚火旺、阴虚阳亢的病理倾向，且对相应致病因素存在明显的易感性。如果长期营养过剩，过食膏粱厚味，则进一步耗阴动火，或者长期受到环境类激素污染物的作用，或者大量、长期摄入含有性激素的药物或食物，或者反复受到社会心理方面不良因素的影响，会导致肾阴、肾阳的平衡失调，出现肾阴虚而相火旺，使生长发育加速，青春期的特征提前出现。此外，还伴有一系列肾阴虚相火旺的证象，如怕热、口渴、颜面潮红、烦躁易怒、五心烦热、盗汗、便秘及舌质红绛或舌边尖红等。

对病程较短、病情较轻的患儿，包括单纯乳房早发育及缓慢变化型真性性早熟患儿，单纯采用中药治疗即可取得满意的治疗效果，一般治疗2~3个月后，患儿的乳腺组织明显的变软，以后渐缩小、消退，子官卵巢也会相应回缩。对病情较重的患儿也能明显改善患儿阴虚火旺的症状，并对患儿骨龄超前有缓解作用。
